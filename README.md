# Proxy VZYN
Aplicativo Android independente, sem conta ou KEY. Importa APKs pelo seletor Android, mostra metadados, permissões, atividades, serviços, certificados, hashes e bibliotecas, guarda relatório local e oferece atalho flutuante arrastável. Não instala, altera ou executa APKs; não reproduz proxy, ADB ou funções proprietárias do aplicativo original.

Android 10–15. JDK 17, SDK 35, Gradle 8.9. Compile com `gradle :app:assembleDebug` ou Actions > Build APK. Baixe o artifact Proxy-VZYN-debug. Para ativar o atalho, conceda a permissão de sobreposição e toque novamente no botão. Desative pelo aplicativo ou pela notificação.
